# 身记 · Body Journal

用一句话记录体重和腰围，让每一点变化都有迹可循。

身记是一个轻量的身体数据记录网站。输入日常表达，就能生成测量记录，并通过表格和趋势图查看自己的变化。

## 在线体验

**[打开身记 →](https://43.142.28.18/)**

手机或电脑均可直接访问，注册账号即可开始记录。

## 主要功能

- **自然语言记录**：输入「现在体重 70，腰围 80 厘米」，即可记录一次测量。
- **饭后标注**：输入「现在饭后 70.2」，趋势图会以橙色菱形标出，表格和导出也保留标注。
- **多次测量保留**：一天可以记录多次，每次测量独立保存。
- **趋势与明细**：查看体重、腰围趋势，以及每次测量的变化。
- **个人账号**：支持注册和登录，每个账号拥有独立的记录空间。
- **编辑与导出**：更正测量记录，或导出为 Excel 可打开的 CSV 文件。

## 使用示例

```text
现在体重 70，腰围 80 厘米
昨天晚上八点半，体重 70.2
腰围 79.5
```

支持中文时间和斤 / 公斤转换。未填写时间时默认记录为当天 08:00，填写「现在」则使用当前时间。

## 本地启动

使用 Node.js 24，无需安装第三方依赖。

```sh
git clone https://github.com/shooterLee414/body-journal.git
cd body-journal
node server.mjs
```

本地开发时打开 [localhost:8793](http://127.0.0.1:8793)；直接使用网站请访问上方的在线体验入口。
